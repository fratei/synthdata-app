# SynthData Frontend

React/Next.js frontend for the SynthData platform.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features (Planned)

- **Schema Builder** — Visual interface for defining data schemas
- **Generation Dashboard** — Monitor active generation jobs
- **Dataset Browser** — Preview and download generated datasets
- **Template Gallery** — Browse and customize pre-built schema templates
